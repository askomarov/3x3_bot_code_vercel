# Handlers Module Structure

Данный модуль содержит обработчики команд для 3x3 Scorer Bot, разбитые на логические группы для улучшения читаемости и поддержки кода.

## Структура модулей

```
app/handlers/
├── __init__.py          # Экспорты модуля
├── base.py              # Базовый класс для всех обработчиков
├── user_commands.py     # Обработчики пользовательских команд
├── admin_commands.py    # Обработчики админских команд
├── game_commands.py     # Обработчики игровых команд и турниров
└── main.py              # Главный класс, объединяющий все обработчики
```

## Описание модулей

### 🔧 `base.py`
Базовый класс `BaseHandler` содержит общую функциональность:
- Логирование действий пользователей
- Отправка сообщений об ошибках
- Проверка прав администратора
- Инициализация подключения к базе данных

### 👤 `user_commands.py`
Класс `UserCommandHandlers` содержит команды для обычных пользователей:
- `/start` - Приветствие и основное меню
- `/help` - Справка по использованию
- `/stats` - Просмотр всех игр
- `/clear` - Очистка личной статистики
- Обработка данных от WebApp
- Создание основной клавиатуры

### 🛡️ `admin_commands.py`
Класс `AdminCommandHandlers` содержит команды только для администратора:
- `👥 All Users` - Просмотр всех пользователей
- `📈 Bot Stats` - Статистика бота
- `🗑️ Admin Clear All` - Полная очистка базы данных
- Создание админской клавиатуры

### 🎮 `game_commands.py`
Класс `GameCommandHandlers` содержит игровые команды:
- `🇷🇸 Tournaments in Serbia` - Поиск турниров в Сербии
- Обработка API запросов к FIBA 3x3

### 🔗 `main.py`
Класс `CommandHandlers` объединяет все обработчики:
- Делегирует вызовы к соответствующим модулям
- Обрабатывает текстовые сообщения (`handle_message`)
- Поддерживает обратную совместимость с существующим кодом

## Преимущества новой структуры

1. **Модульность**: Каждая группа команд в отдельном файле
2. **Читаемость**: Легче найти нужную функцию
3. **Поддержка**: Изменения в одной группе не влияют на другие
4. **Расширяемость**: Легко добавлять новые группы команд
5. **Тестируемость**: Можно тестировать каждый модуль отдельно

## Использование

Импорт и использование остается прежним:

```python
from app.handlers import CommandHandlers

# Инициализация
handlers = CommandHandlers(database)

# Использование
await handlers.start_command(update, context)
await handlers.admin_clear_all_command(update, context)
```

## Миграция

Старый файл `handlers.py` переименован в `handlers_old.py` для резервной копии.
Все существующие импорты продолжают работать без изменений.
